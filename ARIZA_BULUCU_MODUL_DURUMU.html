      ↓

      ↓

  { text, sources, ok, query, confidence }

12. KALAN İŞLER ⏳

  • ⏳ Sayfa numarası doğruluğu: Fiziksel sayfa ≠ baskılı sayfa sorunu. PDF page label okuma ile çözülebilir.
  • ⏳ Sohbet hafızası: Her soru bağımsız. Önceki soruları hatırlamıyor. n8n'de session bazlı hafıza eklenebilir.
  • ⏳ Chunk sayısı artırma: Şu an top-3 chunk gönderiliyor, top-8'e çıkarılabilir.
  • ⏳ Offline mod kalitesi: qwen2.5:7b, Claude kadar detaylı cevap veremiyor. Daha büyük sunucu ile 14b kullanılabilir.
  • ⏳ Yeni manüel eklenince re-index: Otomatik hale getirilmeli (inotify ile izleme).
  • ⏳ Arayüz sunucuya yüklenmesi: argus_chat.html, /var/www veya n8n static klasörüne taşınmalı.
  • ⏳ Birden fazla gemi desteği: Şu an tek gemi (Manta Anadolu). Gemi bazlı klasör + ayrı index yapısı.
